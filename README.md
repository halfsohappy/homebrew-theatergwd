# homebrew-theatergwd

Homebrew tap for [TheaterGWD](https://github.com/halfsohappy/TheaterGWD) tools.

## Install

```bash
brew install halfsohappy/theatergwd/gooey
```

## Formulas

| Formula | Description |
|---------|-------------|
| **gooey** | TheaterGWD Control Center – web-based OSC device manager for theater sensor hardware |
